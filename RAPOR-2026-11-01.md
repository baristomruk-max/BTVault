# BTVault Sağlık Raporu — 1 Kasım 2026

Bu tur, 18 Ekim raporundan sonra sitelerin ne kadarının hâlâ ayakta olduğunu
ve eklenti kodlarının bu sitelerle uyuşup uyuşmadığını yerinde ölçtü.

Yöntem:

1. Her provider klasöründeki `<Provider>.kt` dosyasından `mainUrl` okundu.
2. Alan adları Google DNS (8.8.8.8) ile çözüldü — yerel router birçok yayın
   alan adını `195.175.254.2`'ye (Engelli Web) yönlendiriyor, bu yüzden
   doğrudan yerel DNS ile yapılan test yanıltıcı.
3. `curl --resolve` ile doğru IP'ye sabitlenerek ana sayfa, arama ucu ve
   örnek detay sayfası çekildi.
4. Kodun kullandığı CSS seçicileri / API alanları yakalanan HTML ile
   karşılaştırıldı.

Ham çıktılar: `scripts/health-2026-11-01/`, `scripts/probe-2026-11-01/`,
özet tablolar: `scripts/health-2026-11-01.csv`,
`scripts/health-sel-2026-11-01.csv`.

Yeniden çalıştırmak için:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\health-2026-11-01.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\health-sel-2026-11-01.ps1
```

## Yeniden yazım reçeteleri (sıradaki iş)

HDFilmCehennemi2 tamamlandı (bkz. bölüm 3b). Kalanlar:

### TvDiziler — yeni Nuxt benzeri tema

- Ana sayfa: `https://tvdiziler.tv/` (eski `/home` yok)
- Kategoriler: `/dizi/tur/<tur>` (gerilim, komedi, dram …)
- Detay: `/dizi/<slug>` (örn. `/dizi/behzat-c-izle-full-5`)
- Arama: `POST /search?qr=<kelime>` + `X-Requested-With: XMLHttpRequest`
  (JSON `{"success":...}` / `{"error":...}`)
- Oynatıcı eski `/home/player/oynat/` yolundan farklı; detay sayfasındaki
  `data-*` oynatıcı butonlarından yeni uç bulunmalı.

### HDFilmSitesi — dizifilmizle.to (Nuxt, gömülü JSON)

- Ana sayfa HTML'i içinde `vidmixi` ve film nesnesi gömülü geliyor:
  `title`, `slug`, `poster_url`, `imdb_rating`, `parts` (JSON string:
  `[{"url":"https://vidmixi.com/embed/<hash>", ...}]`).
- Bu yüzden DOM seçicisi yerine gömülü JSON (`__NUXT__` / `self.__next_f`)
  ayrıştırılmalı. `parts[].url` doğrudan `vidmixi` çözücüsüne verilebilir;
  mevcut `BepeakCrypto`/`BepeakModels` ve `vidmixi` çözücüsü korunabilir.
- Film adresi: `/film/<slug>` (örn. `/film/predator-vahsi-topraklar-izle14`).

### FilmKovasi — Next.js + restapi

- Site `filmkovasi.com` artık Next.js; kartlar `/film/<slug>`.
- HTML içinde `https://restapi.filmkovasi.com` referansı var; site kendi
  API'sinden besleniyor. Ağ sekmesinden `restapi` uçları (liste/arama/detay)
  çıkarılıp doğrudan JSON ile çalışılmalı.

## ISS (BTK) DNS engeli

Testler Google DNS ile yapıldı; bu yüzden "site açıldı" sonucu ISS engelini
göstermiyor. Daha önce engelli olduğu doğrulanan adresler için çözüm hâlâ
aynı: telefon/box DNS'ini `8.8.8.8` + `1.1.1.1` yapmak veya VPN kullanmak.
Engel DNS seviyesinde olduğu için kod tarafında yapılabilecek bir şey yok.
